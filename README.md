## Sobre el proyecto

PortumSport es una empresa ficticia dedicada a la venta de
indumentaria, calzado y accesorios deportivos. Cuenta con tres
sucursales, un depósito central y una tienda online.

El proyecto propone un sistema para consultar stock por ubicación,
registrar ventas, ingresos y traslados de mercadería, analizar
productos más vendidos y de baja rotación, y registrar solicitudes
de productos no disponibles.
